# Python for the Win

pftw installs official Python on Windows for your user account, without the Microsoft Store, MSI installers,
the Python Install Manager, administrator rights or Program Files.

**The short version:** download `pftw.exe`, double-click it, press Enter until it's done, then open a new
terminal and type `python`. If that worked, you don't need anything on this site.

## Why this exists

Python on Windows used to be "download the installer, click Next". That installer is being retired in favour
of the Python Install Manager, which ships through the Microsoft Store or an MSI. pftw keeps the simple path:
one program, the official python.org builds, and nothing you didn't ask for.
Read the [motivation](https://github.com/matthewdeanmartin/python_for_the_win/blob/main/spec/motivation.md)
and the [full specification](https://github.com/matthewdeanmartin/python_for_the_win/blob/main/spec/spec.md).

See also the [changelog](https://github.com/matthewdeanmartin/python_for_the_win/blob/main/CHANGELOG.md)
and the [source code](https://github.com/matthewdeanmartin/python_for_the_win).

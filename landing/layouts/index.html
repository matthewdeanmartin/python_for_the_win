THE SHORT PATH / 01

Three steps to
a useful prompt.

Already have Python? The PyPI package gives you pftw from the terminal. Starting from zero? Download the Windows executable from the project releases and follow the prompts.

Installation guide ↗
01

Get pftw

Install the pftw package through an existing Python, or get the Windows executable from GitHub Releases.

python -m pip install pftw
02

Install Python

Run the installer for your account. The executable has an interactive flow; the module command works from a terminal.

python -m pftw install
03

Use it

Open a new terminal after installation, then check the Python that resolves on your path.

python --version

Keep a version nearby

Install a specific release line alongside your existing Python and call its versioned shim.

See what gets installed.

pftw installs official Python releases and manages user-level commands. Its documentation explains PATH choices, portable installs, offline downloads, and removal before you make changes to a machine.
